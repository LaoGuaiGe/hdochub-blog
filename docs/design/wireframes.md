## 0. 文档说明

本文档以 ASCII 线框图 + Markdown 表格的方式描述全站页面布局。所有页面遵循《设计规范文档 design-system.md》中的野兽派规范：

- 全站通用框架：顶部导航栏（`64px` 高）+ 主内容区 + 页脚（黑底白字）。
- 全站容器最大宽度：前台 `1200px`，后台 `1280px`，文章正文 `680px`。
- 区域分隔一律使用 `2px solid #000` 硬边框，无圆角无阴影。
- 图例说明：

| 符号 | 含义 |
|------|------|
| `┌─┐│└─┘` | 区域边框（2px 黑实线） |
| `[ ]` | 按钮 / 输入框 / 卡片等组件 |
| `■` | 黑底白字区块（深色块） |
| `░` | 浅灰底色区（`#F5F5F5`） |
| `▓` | 黄底高亮区（`#FFFF00`，选中/命中态） |
| `…` | 内容省略 / 同类元素重复 |

### 0.1 全站通用页脚（Footer）

所有前台页面底部统一为深色页脚：

```
┌──────────────────────────────────────────────────────────┐
│ ■ #000000 黑底 / #FFFFFF 白字                              │
│  hdochub 个人技术博客        [RSS]   [关于]   [友链]        │
│  © 2026 hdochub · 备案号 京ICP备XXXXXX号                   │
│  Powered by hdochub · blog.hdochub.com                    │
└──────────────────────────────────────────────────────────┘
```

### 0.2 全站通用顶部导航（Navbar）

```
┌──────────────────────────────────────────────────────────────────────┐
│ [hdochub]   首页  分类  标签  归档  关于  友链        [🔍 搜索]  [登录] [注册] │
└──────────────────────────────────────────────────────────────────────┘
  └─ 2px solid #000 底边 ─┘
```

- 已登录状态右侧变为：`[头像方块] 用户名 ▾`（下拉：用户后台 / 写文章 / 退出）。
- 当前所在页对应的导航项加 `2px solid #000` 顶边线标识。
- 移动端：菜单折叠为 `≡`，搜索折叠为图标。

#### 1.2 关键元素说明

| 区域 | 元素 | 排列规则 |
|------|------|----------|
| Navbar | 站点标题、导航菜单、搜索、登录/注册 | 见 0.2 |
| 排序工具栏 | 排序切换（时间倒序默认/阅读量）、分类筛选下拉、标签筛选下拉 | 横向排列，`2px` 边框包裹，当前排序项黑底白字 |
| 文章列表 | 文章卡片（封面图、分类标签、标题、摘要、标签、作者/时间/阅读量/点赞数） | PC 三列网格，`gap:24px`；卡片样式见设计规范 6.4 |
| 分页器 | 上一页/页码/下一页 | 居中或左对齐，见设计规范 6.7 |
| 侧边栏 | 搜索框、分类列表（含文章数）、标签云、热门文章 Top5 | 垂直堆叠，各模块 `2px` 边框分隔 |
| 页脚 | 版权、备案号、RSS、关于、友链链接 | 见 0.1 |

#### 1.3 响应式适配

| 断点 | 适配方案 |
|------|----------|
| PC（>1024px） | 主内容（8栏）+ 侧边栏（4栏）双栏；卡片三列 |
| 平板（768-1024px） | 隐藏侧边栏，侧边栏内容下移至列表下方单列展示；卡片两列；搜索收缩为图标 |
| 移动端（<768px） | 导航折叠汉堡菜单；卡片单列；侧边栏模块折叠为可展开区块；排序工具栏变为顶部下拉 |

#### 2.2 关键元素说明

| 区域 | 元素 | 排列规则 |
|------|------|----------|
| 面包屑 | 首页 > 分类 > 文章标题 | 顶部一行，等宽小字，`>` 分隔 |
| 文章头部 | 封面图、分类标签、H1 标题、标签组、作者头像+昵称、发布时间、阅读量、字数、阅读时长 | 垂直堆叠，元信息一行等宽小字 |
| 正文 | Markdown 渲染 HTML、代码块高亮、图片自适应 | 最大宽 `680px`，正文用无衬线字体，标题/代码等宽 |
| TOC 侧边栏 | 根据 H2/H3 自动生成目录，当前章节黄底高亮 | 右侧固定，宽度 `200px`；点击锚点跳转 |
| 点赞区 | 点赞按钮+点赞数 | 正文底部，登录用户可点；未登录点击跳转登录 |
| 评论区 | 评论列表（楼中楼最多3层）+ 评论输入框 | 按时间正序；嵌套缩进；输入框登录后可用，否则置灰提示登录 |
| 上下篇导航 | 上一篇/下一篇链接 | 两栏对分 |
| 相关文章 | 同分类或同标签文章列表 | 双列文字链接 |

#### 2.3 响应式适配

| 断点 | 适配方案 |
|------|----------|
| PC（>1024px） | 主内容 + 右侧 TOC 双栏；TOC 固定跟随滚动 |
| 平板（768-1024px） | 隐藏右侧 TOC，正文单栏居中；目录折叠为正文顶部「目录 ▾」展开按钮 |
| 移动端（<768px） | 单栏满宽；封面图满宽；评论区嵌套改为缩进+竖线；上下篇纵向堆叠 |

## 附录 C：交互状态补充说明

所有页面的交互态统一遵循《设计规范文档》第 8 章：

- 列表项 / 卡片 / 表格行：Hover 反色或黄底命中。
- 按钮：Hover 反色，Active 下移位移，Focus 黄色 outline。
- 表单：失焦校验，错误红框红字。
- 删除/封禁/下架等破坏性操作：均需二次确认弹窗（黑底白字标题栏 + 危险按钮）。
- 加载态：`LOADING...` 文字或黑白方块进度条。
- 空状态：`NO RESULTS` / `NO DATA` 文字 + 引导按钮。
