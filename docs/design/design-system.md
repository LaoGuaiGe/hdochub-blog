## 0. 文档说明

本规范基于 PRD 1.3 节「设计风格」中明确的野兽派（Brutalism）要求制定，作为全站视觉与交互的统一基准。所有前端实现必须严格遵循本文档，不得擅自引入圆角、阴影、渐变等违背野兽派原则的样式。

本规范的核心铁律（任何情况下不可破坏）：

1. **无圆角** — `border-radius: 0`，全局禁止圆角。
2. **无阴影** — `box-shadow: none`，禁止任何软阴影、发光、模糊投影。
3. **无渐变** — 禁止 `linear-gradient` / `radial-gradient`，所有颜色均为纯色填充。
4. **硬边框** — 区域分隔一律使用实线边框，边框即装饰。
5. **高对比** — 以黑白为绝对主色，撞色仅用于强调与状态。
6. **内容至上** — 去除一切非功能性装饰，不使用装饰性图标插画、不使用花哨动效。

## 1. 设计理念：野兽派（Brutalism）核心原则

野兽派源自建筑学「Béton brut」（裸露混凝土），移植到 Web 即「裸露网页的本质」。对本项目而言，其核心原则如下：

### 1.1 五项核心原则

| 原则 | 含义 | 在本项目的体现 |
|------|------|----------------|
| 原始粗犷 | 暴露结构，不做表面美化 | 裸露的边框、等宽字体、可见的网格线，让页面像「未粉刷的混凝土」 |
| 极简克制 | 只保留功能性元素 | 去除装饰图标、插画、背景纹理；视觉元素 100% 服务于内容 |
| 高对比 | 黑白为底，反差强烈 | 背景纯白、文字纯黑，必要时整块黑白翻转；状态用纯色撞色 |
| 硬朗几何 | 直角、直线、硬边 | 一切元素直角，分隔靠边框而非留白过渡 |
| 内容至上 | 阅读体验优先 | 文章正文获得最大视觉权重，UI 控件退让到最小必要尺寸 |

### 1.2 设计取向说明

- **为何用野兽派**：目标用户是工程师，习惯终端、代码、命令行美学。等宽字体、硬边框、高对比的视觉语言与工程师的日常工具（终端、IDE）天然契合，降低认知迁移成本。
- **撞色策略**：纯红 `#FF0000`、纯黄 `#FFFF00` 为仅有的两个撞色，分别承担「危险/错误」与「警示/强调/交互命中」语义，绝不滥用，使每次撞色都形成强烈信号。
- **动效取向**：野兽派反平滑、反拟物。过渡时长统一 `0.05s` 线性（近乎瞬切），仅用于状态切换的可感知反馈，禁止弹跳、淡入淡出、滑动等「精致」动画。

## 2. 色彩系统

### 2.1 设计原则

- 黑白为绝对主色，占比 ≥ 85%。
- 灰阶仅用于次要文字、分隔线、禁用态，不作为大面积底色。
- 撞色（红、黄）合计占比 ≤ 5%，且仅出现在状态、强调、交互命中处。
- 全部使用纯色（HEX），禁止透明度叠加（`rgba` 仅在极个别遮罩场景使用，且需评审）。

### 2.2 基础色板

| 类别 | 名称 | 色值 | 用途 |
|------|------|------|------|
| 主色 | 纯黑 Black | `#000000` | 主文字、边框、主按钮底色、深色区块底色 |
| 主色 | 纯白 White | `#FFFFFF` | 页面主背景、浅色区块底色、深色底上的文字 |
| 撞色 | 纯红 Red | `#FF0000` | 错误/危险态、删除操作、错误提示 |
| 撞色 | 纯黄 Yellow | `#FFFF00` | 警告、强调高亮、交互命中态（focus、选中、搜索匹配） |

### 2.3 中性灰阶

| 名称 | 色值 | 用途 |
|------|------|------|
| Gray-900 | `#1A1A1A` | 代码块深色背景、深色面板次级底色 |
| Gray-700 | `#4D4D4D` | 次要正文、说明文字 |
| Gray-500 | `#808080` | 代码注释、占位符、辅助文字 |
| Gray-300 | `#B3B3B3` | 禁用态文字 |
| Gray-200 | `#E0E0E0` | 浅色分隔线、表格行分隔、次要边框 |
| Gray-100 | `#F5F5F5` | 次级背景（表格斑马纹、卡片 hover 前的极浅底、输入框底色） |

### 2.4 状态色

| 状态 | 色值 | 文字色 | 用途 |
|------|------|--------|------|
| 成功 Success | `#008000` | `#FFFFFF` | 操作成功提示、发布成功、评论通过 |
| 警告 Warning | `#FFFF00` | `#000000` | 待审核、草稿态、下架提示、表单校验警告 |
| 错误 Error | `#FF0000` | `#FFFFFF` | 校验失败、删除确认、系统错误 |
| 信息 Info | `#0000FF` | `#FFFFFF` | 一般性提示、新消息通知 |

> 说明：黄色 `#FFFF00` 同时是撞色与警告色。为避免歧义，黄色作为「警告/命中」时底色配黑字；作为「交互命中高亮」（如搜索词高亮、选中行）时也用黄底黑字。红色统一表示破坏性/错误。

### 2.5 语义映射总表

| 场景 | 背景 | 文字 | 边框 |
|------|------|------|------|
| 页面主背景 | `#FFFFFF` | `#000000` | — |
| 深色区块（页脚/导航选中） | `#000000` | `#FFFFFF` | — |
| 卡片 | `#FFFFFF` | `#000000` | `#000000` |
| 卡片 hover | `#000000` | `#FFFFFF` | `#000000` |
| 主按钮 | `#000000` | `#FFFFFF` | `#000000` |
| 主按钮 hover | `#FFFFFF` | `#000000` | `#000000` |
| 危险按钮 | `#FF0000` | `#FFFFFF` | `#000000` |
| 危险按钮 hover | `#FFFFFF` | `#FF0000` | `#FF0000` |
| 输入框 | `#FFFFFF` | `#000000` | `#000000` |
| 输入框 focus | `#FFFFFF` | `#000000` | `#000000`（3px）+ `#FFFF00` 硬外框（outline） |
| 标签（描边） | `#FFFFFF` | `#000000` | `#000000` |
| 标签（实心） | `#000000` | `#FFFFFF` | `#000000` |
| 选中/命中高亮 | `#FFFF00` | `#000000` | — |

### 2.6 配色禁忌

- 禁止使用渐变色（任何 `gradient`）。
- 禁止使用半透明叠加作为大面积底色。
- 禁止使用与主色板无关的「柔和色」（如莫兰迪、马卡龙色系）。
- 红与黄不得相邻大面积使用，以免视觉刺眼且语义混乱。

## 3. 字体系统

### 3.1 字体族

本项目以等宽字体（monospace）为视觉核心，体现工程师气质。

| 用途 | 字体栈 | 说明 |
|------|--------|------|
| UI / 标题 / 元信息 | `ui-monospace, SFMono-Regular, 'SF Mono', Menlo, Consolas, 'Liberation Mono', 'Courier New', monospace` | 全站导航、按钮、标签、标题、卡片元信息、表单标签 |
| 文章正文（长文阅读） | `'Helvetica Neue', Arial, 'PingFang SC', 'Microsoft YaHei', sans-serif` | 仅用于文章详情页 Markdown 渲染后的正文段落，保证长文可读性 |
| 代码 | `ui-monospace, SFMono-Regular, Menlo, Consolas, 'Liberation Mono', monospace` | 代码块与行内代码 |

> 理由：等宽字体强化野兽派气质且契合工程师习惯；但长篇技术文章若全程等宽会降低阅读速度，故正文段落采用无衬线系统字体，仅在正文内部「回到等宽」处理标题与代码，形成节奏。文章正文以外的所有界面元素一律等宽。

### 3.2 字号层级

基础字号以浏览器默认 `16px` 为 `1rem`。下表为 PC 端基准，响应式下移动端按第 7 章断点规则缩放。

| 层级 | 名称 | 字号（PC） | 字号（移动端） | 字重 | 行高 | 字间距 | 用途 |
|------|------|-----------|---------------|------|------|--------|------|
| H1 | 显示标题 | `2.5rem` (40px) | `2rem` (32px) | 700 | 1.2 | `-0.02em` | 文章详情页标题、注册/登录页大标题 |
| H2 | 章节标题 | `2rem` (32px) | `1.75rem` (28px) | 700 | 1.25 | `-0.01em` | 页面区块标题、文章内 H2 |
| H3 | 次级标题 | `1.5rem` (24px) | `1.25rem` (20px) | 700 | 1.3 | `0` | 卡片组标题、后台侧边栏分组标题 |
| H4 | 小节标题 | `1.25rem` (20px) | `1.125rem` (18px) | 700 | 1.35 | `0` | 文章内 H4、面板标题 |
| H5 | 列表标题 | `1.125rem` (18px) | `1rem` (16px) | 700 | 1.4 | `0` | 文章卡片标题、表单区段标题 |
| H6 | 最小标题 | `1rem` (16px) | `0.9375rem` (15px) | 700 | 1.4 | `0` | 表格列头、次级小标题 |
| Body | 正文 | `1rem` (16px) | `0.9375rem` (15px) | 400 | 1.7 | `0` | 文章正文段落 |
| Body-UI | 界面正文 | `0.9375rem` (15px) | `0.875rem` (14px) | 400 | 1.5 | `0` | 卡片摘要、说明文字、表格内容 |
| Small | 小字 | `0.8125rem` (13px) | `0.75rem` (12px) | 400 | 1.5 | `0` | 元信息（作者/时间/阅读量）、表单辅助文字 |
| Caption | 极小字 | `0.75rem` (12px) | `0.6875rem` (11px) | 400 | 1.4 | `0.02em` | 标签文字、按钮内文字、版权信息 |
| Code | 代码 | `0.875rem` (14px) | `0.8125rem` (13px) | 400 | 1.6 | `0` | 代码块、行内代码 |

### 3.3 字重

| 名称 | 字重值 | 用途 |
|------|--------|------|
| Regular | 400 | 正文、说明、表格内容 |
| Medium | 500 | 次级强调（少用） |
| Bold | 700 | 所有标题、按钮文字、标签文字、表头、强调元信息 |

> 野兽派偏好粗壮字重。标题一律 700；正文 400。禁止使用 300（light）等细字重，因其削弱粗犷感。

### 3.4 行高

| 场景 | 行高 |
|------|------|
| 标题（H1-H6） | 1.2 ~ 1.4 |
| 文章正文段落 | 1.7（长文阅读舒适区） |
| 界面正文 / 表格 | 1.5 |
| 代码块 | 1.6 |
| 单行控件（按钮/标签） | 1 |

### 3.5 排版规则

- 段落间距：文章正文段落间 `margin-bottom: 1rem`。
- 标题与正文间距：标题下方 `margin-bottom: 0.75rem`，标题上方 `margin-top: 1.5rem`（首个标题无上边距）。
- 文章正文最大宽度：`680px`（约 65-75 中文字符/行，阅读最佳行宽），超出居中。
- 等宽 UI 文字默认 `letter-spacing: 0`；大号显示标题（H1）使用 `-0.02em` 收紧，避免等宽字间距过大。
- 文章正文中的行内代码、链接、加粗等见「组件规范」与「代码高亮」章节。

## 4. 间距系统

### 4.1 基础单位

基础间距单位为 `4px`，所有间距必须是 `4px` 的整数倍，禁止使用 `5px`、`7px` 等非整数倍数值。

### 4.2 间距层级

| Token | 数值 | 用途 |
|-------|------|------|
| `space-1` | `4px` | 图标与文字间距、紧凑元素内微间距 |
| `space-2` | `8px` | 标签内边距、按钮内边距纵向、小元素间距 |
| `space-3` | `12px` | 输入框内边距、行内元素间距 |
| `space-4` | `16px` | 卡片内边距、段落间距、列表项间距 |
| `space-6` | `24px` | 区块内边距、表单字段间距 |
| `space-8` | `32px` | 区块间距、面板内边距 |
| `space-12` | `48px` | 页面大区块间距 |
| `space-16` | `64px` | 页面主区块垂直间距、首屏留白 |

### 4.3 使用规则

- **页面外边距（容器）**：PC 端左右 `48px`，平板 `24px`，移动端 `16px`。
- **内容最大宽度**：列表页容器 `1200px`；文章正文 `680px`；后台管理表格区 `1280px`。
- **组件内边距**：按钮 `8px 16px`；输入框 `12px`；卡片 `16px`；面板 `24px`。
- **网格间距（gap）**：卡片网格 `24px`；表单字段 `24px`；标签组 `8px`。
- 禁止使用 `margin: auto` 之外的非 4px 倍数值。

## 5. 边框系统

### 5.1 边框宽度

| Token | 数值 | 用途 |
|-------|------|------|
| `border-0` | `0` | 无边框（深色区块内部） |
| `border-1` | `1px` | 表格行分隔线、次要分隔线 |
| `border-2` | `2px` | 默认边框（卡片、输入框、按钮、标签） |
| `border-3` | `3px` | 强调边框（focus 态、hover 加粗态） |
| `border-4` | `4px` | 页面主分区边框、顶部导航底边、重强调 |

### 5.2 边框颜色

| 名称 | 色值 | 用途 |
|------|------|------|
| 边框-主 | `#000000` | 默认实线边框 |
| 边框-浅 | `#E0E0E0` | 表格行分隔、次要分隔 |
| 边框-红 | `#FF0000` | 危险态边框、错误输入框 |
| 边框-黄 | `#FFFF00` | 选中态边框、命中高亮边框 |

### 5.3 圆角

**全局圆角为 `0`。** 任何元素 `border-radius: 0`，无例外。

### 5.4 边框样式约定

- 默认实线 `solid`，禁止 `dashed` / `dotted` 作为主边框（仅禁用态或占位可用 `dashed` 表示「未填充」）。
- 边框是野兽派的主要装饰手段，区域分隔「用边框而非留白」。
- 嵌套结构通过边框叠加体现层级，而非阴影。

### 5.5 分隔线

| 场景 | 规格 |
|------|------|
| 水平分隔线（区块间） | `2px solid #000000` |
| 表格行分隔 | `1px solid #E0E0E0`，表头底部 `2px solid #000000` |
| 卡片间分隔 | 共享 `2px solid #000000` 边框（相邻边框合并，不双线） |

## 6. 组件规范

### 6.1 按钮（Button）

按钮是野兽派交互的核心载体，通过「黑白翻转」表达状态。

#### 6.1.1 主按钮（Primary）

| 属性 | 默认 | Hover | Active | Focus | Disabled |
|------|------|-------|--------|-------|----------|
| 背景 | `#000000` | `#FFFFFF` | `#FFFFFF` | `#000000` | `#F5F5F5` |
| 文字 | `#FFFFFF` | `#000000` | `#000000` | `#FFFFFF` | `#B3B3B3` |
| 边框 | `2px solid #000` | `2px solid #000` | `3px solid #000` | `2px solid #000` | `2px solid #E0E0E0` |
| 位移 | — | — | `transform: translate(2px,2px)` | — | — |
| 光标 | `pointer` | `pointer` | `pointer` | — | `not-allowed` |

- 内边距：`8px 16px`
- 字号：`0.875rem`，字重 700，等宽
- 圆角：0
- 过渡：`all 0.05s linear`

#### 6.1.2 次按钮（Secondary）

| 属性 | 默认 | Hover | Active | Disabled |
|------|------|-------|--------|----------|
| 背景 | `#FFFFFF` | `#000000` | `#000000` | `#FFFFFF` |
| 文字 | `#000000` | `#FFFFFF` | `#FFFFFF` | `#B3B3B3` |
| 边框 | `2px solid #000` | `2px solid #000` | `3px solid #000` | `2px solid #E0E0E0` |

- 其余同主按钮。

#### 6.1.3 危险按钮（Danger）

| 属性 | 默认 | Hover | Active | Disabled |
|------|------|-------|--------|----------|
| 背景 | `#FF0000` | `#FFFFFF` | `#FFFFFF` | `#F5F5F5` |
| 文字 | `#FFFFFF` | `#FF0000` | `#FF0000` | `#B3B3B3` |
| 边框 | `2px solid #000` | `2px solid #FF0000` | `3px solid #FF0000` | `2px solid #E0E0E0` |

- 仅用于删除、下架、封禁等破坏性操作。
- 危险按钮触发前必须配合二次确认弹窗（见 6.10）。

#### 6.1.4 文字按钮（Text Button）

- 无背景无边框，文字 `#000000`，hover 时加 `2px solid #000` 底边线（下划线式），或文字变黄 `#FFFF00` 背景黑字。
- 用于「查看更多」「展开/折叠」等轻量操作。

#### 6.1.5 按钮组

- 相邻按钮共享边框，中间分隔线 `2px solid #000`，不产生双线。
- 按钮组整体外边框 `2px solid #000`。

### 6.2 输入框（Input / Textarea）

| 属性 | 默认 | Focus | 错误 | 禁用 |
|------|------|-------|------|------|
| 背景 | `#FFFFFF` | `#FFFFFF` | `#FFFFFF` | `#F5F5F5` |
| 文字 | `#000000` | `#000000` | `#000000` | `#B3B3B3` |
| 边框 | `2px solid #000` | `3px solid #000` | `2px solid #FF0000` | `2px solid #E0E0E0` |
| 占位符 | `#808080` | `#808080` | `#808080` | `#B3B3B3` |

- 内边距：`12px`
- 字号：`0.9375rem`，等宽
- 圆角：0
- Focus 外框：`outline: 4px solid #FFFF00; outline-offset: 0`（黄色实心硬外框，非模糊发光，用于可访问性聚焦指示）
- Textarea 同输入框规则，最小高度 `120px`，可纵向拉伸。
- 输入框前缀图标（如搜索）使用等宽字符或极简线性图标，置于框内左侧，不破坏边框。

### 6.3 表单（Form）

- 字段标签：置于输入框上方，等宽，`0.875rem`，700 字重，`#000000`。
- 标签与输入框间距 `8px`。
- 必填标记：标签后接红色星号 `*`（`#FF0000`）。
- 辅助/错误文字：输入框下方，`0.8125rem`，错误为 `#FF0000`，提示为 `#4D4D4D`。
- 字段间距：`24px`。
- 复选框 / 单选框：原生控件加 `2px solid #000` 边框，选中态背景 `#000000`、勾选符号 `#FFFFFF` 或 `#FFFF00`。圆角 0。
- 开关（Toggle）：矩形滑块，宽 `48px` 高 `24px`，关闭=`#FFFFFF` 底黑边滑块在左，开启=`#000000` 底滑块（`#FFFF00`）在右。

### 6.4 卡片（Card）

文章列表卡片是前台核心组件。

```
+----------------------------------------------------+
| [封面图 16:9 / 可选]                                |
+----------------------------------------------------+
```

- 整体：`2px solid #000`，无圆角，无阴影。
- 内部分区使用 `2px solid #000` 横线分隔，形成网格感。
- 背景 `#FFFFFF`；Hover：整卡背景翻转为 `#000000`、文字翻转为 `#FFFFFF`（封面图保持，标签描边翻为白底黑字）。
- 封面图：充满卡片宽度，`object-fit: cover`，无圆角。
- 摘要：`-webkit-line-clamp: 2` 截断。
- 元信息行：等宽小字，`0.8125rem`。
- 卡片网格：PC 三列，平板两列，移动端单列；间距 `24px`，相邻边框合并。

### 6.5 标签（Tag）

| 变体 | 默认 | Hover |
|------|------|-------|
| 描边标签 | `#FFFFFF` 底 / `#000000` 字 / `2px solid #000` | `#000000` 底 / `#FFFFFF` 字 |

- 内边距：`2px 8px`
- 字号：`0.75rem`，700 字重，等宽
- 圆角：0
- 标签云：根据文章数量映射字号（`0.75rem` ~ `1.5rem`），数量越多字号越大、越偏向实心。

### 6.6 导航栏（Navbar）

```
+------------------------------------------------------------------+

+------------------------------------------------------------------+
```

- 固定顶部（`position: sticky; top: 0`），`z-index: 100`。
- 高度 `64px`，底边 `2px solid #000`。
- 背景 `#FFFFFF`。
- 站点标题：等宽 700，`1.25rem`，可点击回首页。
- 导航项：等宽 `0.9375rem`，默认黑字无底；当前页项加 `2px solid #000` 顶边线（active 标识）；hover 黑底白字。
- 右侧操作区：搜索框（图标+输入）、登录/注册按钮或用户头像方块+下拉。
- 移动端：导航项折叠为汉堡菜单（`≡` 字符按钮，2px 黑边），点击展开全宽下拉面板（黑底白字）。

### 6.7 分页器（Pagination）

```

```

- 每个页码为一个方块按钮：`40px × 40px`，`2px solid #000`，等宽居中。

- 非当前页：`#FFFFFF` 底 / `#000000` 字，hover 翻转。

- 单元格：`#FFFFFF` 底 / `#000000` 字；斑马纹奇数行 `#F5F5F5`。
- 行分隔：`1px solid #E0E0E0`。
- 行 hover：整行背景 `#FFFF00`（黄底黑字，命中态）。
- 表格外边框 `2px solid #000`。
- 操作列：文字按钮（编辑/删除），删除为红色文字 `#FF0000`，hover 加底边线。
- 移动端：表格横向滚动（`overflow-x: auto`），保留关键列，次要列可折叠。

### 6.9 侧边栏（Sidebar）

前台文章详情页 TOC、后台导航侧边栏。

- 宽度：`240px`（后台）/ `200px`（前台 TOC）。
- 边框：右侧 `2px solid #000`（左置侧边栏）或左侧。
- 后台侧边栏菜单项：等宽 `0.9375rem`，默认黑字；hover 黑底白字；active 项 `#FFFF00` 底黑字 + 左侧 `4px solid #000` 标识条。

- 标题栏：`#000000` 底 / `#FFFFFF` 字，`2px solid #000` 底边。
- 内容区白底黑字，内边距 `24px`。
- 操作栏：右对齐按钮组（取消=次按钮，确认=主按钮/危险按钮）。

## 7. 响应式断点与布局规则

### 7.1 断点定义

| 断点名称 | 范围 | 容器最大宽度 | 左右外边距 |
|----------|------|--------------|-----------|
| PC（Desktop） | `> 1024px` | `1200px`（列表）/ `1280px`（后台） | `48px` |
| 平板（Tablet） | `768px ~ 1024px` | `100%` | `24px` |
| 移动端（Mobile） | `< 768px` | `100%` | `16px` |

### 7.2 布局规则

#### PC（> 1024px）

- 顶部导航横向展开，全部菜单项可见。
- 文章列表：三列卡片网格（`gap: 24px`）。
- 文章详情页：主内容（`680px`）+ 右侧 TOC 侧边栏（`200px`），双栏。
- 后台：左侧导航侧边栏（`240px`）+ 右侧主内容区，双栏固定。
- 前台首页可有三栏（主列表 + 右侧信息栏：搜索/分类/标签云/热门）。

#### 平板（768 ~ 1024px）

- 导航菜单保留横向，但减少间距；右侧搜索收缩为图标。
- 文章列表：两列卡片网格。
- 文章详情页：隐藏右侧 TOC 或折叠为顶部下拉；正文单栏居中。
- 后台：侧边栏改为可折叠图标条（`64px` 宽，仅图标），点击展开。
- 首页右侧信息栏下移至列表下方。

#### 移动端（< 768px）

- 导航折叠为汉堡菜单 `≡`，点击展开全宽黑底白字下拉面板。
- 文章列表：单列卡片。
- 文章详情页：单栏，正文满宽，TOC 折叠为详情顶部「目录」展开按钮。
- 后台：侧边栏改为底部 Tab 栏或抽屉式（左滑展开黑底白字）。
- 表格横向滚动，关键操作以图标按钮呈现。
- 表单单列堆叠，按钮满宽。

### 7.3 网格系统

- 采用 12 栏 CSS Grid / Flexbox。
- 栏间距（gutter）：PC `24px`，平板 `16px`，移动端 `16px`。
- 断点切换使用 `min-width` 移动优先（Mobile-first）写法。

### 7.4 最小支持宽度

- 最小支持 `320px` 宽度，保证小屏不破版。
- 低于 `375px` 时字号降至移动端规格（见 3.2）。

## 8. 交互规范

### 8.1 状态总览

| 状态 | 视觉表现 | 实现方式 |
|------|----------|----------|
| 默认 Default | 组件基础样式 | — |
| 悬停 Hover | 黑白翻转（反色）；或边框由 `2px` 加粗至 `3px` | `:hover` |
| 激活 Active | 翻转态 + `transform: translate(2px,2px)` 下移位移，模拟「按下」 | `:active` |
| 聚焦 Focus | `outline: 4px solid #FFFF00`（黄色硬外框），保证可访问性 | `:focus-visible` |
| 选中 Selected/Active-tab | `#FFFF00` 底 / 黑字，或黑底白字翻转 | `.is-active` |
| 禁用 Disabled | 灰底 `#F5F5F5` / 灰字 `#B3B3B3` / 浅边框 `#E0E0E0` / `cursor: not-allowed` | `:disabled` |
| 加载 Loading | 等宽文字 `LOADING...` 或方块进度条（黑白分块递进），禁用旋转 spinner 拟物动效 | — |

### 8.2 过渡动效

- 全站过渡时长统一 `0.05s`，缓动函数 `linear`。
- 仅应用于颜色、边框、位移等状态切换属性。
- 禁止：弹跳（`cubic-bezier` 弹性）、淡入淡出长动画、滑动展开、旋转、缩放呼吸等「精致」动效。
- 页面切换无路由过渡动画，直接渲染。

### 8.3 反色规则（核心交互语言）

野兽派的交互核心是「黑白翻转」，统一规则：

- 默认浅底深字 → Hover 深底浅字。
- 默认深底浅字 → Hover 浅底深字。
- 边框颜色在翻转中保持 `#000000`（除非危险态用红）。
- 翻转应用于：按钮、卡片、导航项、标签、表格行、分页项、菜单项。

### 8.4 聚焦可访问性

- 所有可交互元素必须可见 focus 态：`outline: 4px solid #FFFF00`。
- 使用 `:focus-visible` 仅在键盘聚焦时显示，鼠标点击不显示外框（避免视觉干扰）。
- 焦点顺序遵循 DOM 顺序，支持 Tab 键完整导航。

### 8.5 链接

- 文章正文链接：默认 `#000000` + `2px solid #000` 底边线；hover 黑底白字（翻转）；访问过 `#4D4D4D`。
- 界面链接（如「查看全部」）：文字按钮样式。

### 8.6 加载与空状态

- 加载：黑白方块进度条或 `LOADING...` 等宽文字闪烁（`0.5s` 切换可见性）。
- 空状态：居中等宽文字 `NO RESULTS` + 说明 + 次按钮（如「返回首页」「浏览分类」），边框包裹。

### 8.7 表单交互

- 输入校验即时反馈：失焦校验，错误时边框变红 `#FF0000`，下方红色提示文字。
- 提交时按钮显示 `SUBMITTING...` 并禁用，防止重复提交。
- 密码强度：用黑白方块条表示（弱=1 格黑，强=4 格黑），无颜色渐变。

## 9. 代码高亮配色方案

技术博客的核心阅读对象是代码，需提供高对比、可读性强的代码主题。本项目定义「Brutal Terminal」深色主题，呼应终端美学。

### 9.1 代码块容器

- 背景：`#000000`（纯黑）。
- 外边框：`2px solid #000000`（与卡片边框一致）。
- 圆角：0。
- 内边距：`16px`。
- 字号：`0.875rem`，行高 `1.6`，等宽字体。
- 顶部语言标签栏：`#000000` 底 / `#FFFF00` 字，等宽 `0.75rem`，显示语言名与「复制」按钮（hover 翻转）。
- 行号：左侧 `#4A4A4A` 色，与代码间 `1px solid #333` 分隔，`padding-right: 16px`。
- 当前行高亮：`#1A1A1A` 背景。
- 选中：`#FFFF00` 背景 / `#000000` 字。

| 运算符 Operator | `#FFFFFF` | 700 | 白色加粗 |

| 行号 Line-number | `#4A4A4A` | 400 | 暗灰 |

### 9.3 行内代码（Inline Code）

- 背景：`#FFFF00`（纯黄）。
- 文字：`#000000`（黑）。
- 内边距：`2px 6px`。
- 边框：`2px solid #000000`。
- 字号：较正文小一档（`0.875em`），等宽。
- 圆角：0。

> 行内代码采用「黄底黑字」高亮，使代码片段在正文中如荧光标记般跳出，符合野兽派的撞色强调逻辑，且与深色代码块形成内外对比。

### 9.4 引用块（Blockquote）

- 左侧 `4px solid #000000` 竖线。
- 背景 `#F5F5F5`。
- 内边距 `16px`。
- 文字 `#4D4D4D`，斜体。

### 9.5 行内强调

| 元素 | 样式 |
|------|------|
| 加粗 `**` | 字重 700，黑色 |
| 斜体 `*` | 斜体 |
| 删除线 `~~` | `text-decoration: line-through`，色 `#808080` |
| 行内代码 | 见 9.3 |
| 链接 | 见 8.5 |

## 10. 图标规范

- 图标风格：极简单色线性图标（stroke `2px`，无填充），或直接使用等宽字符/符号（`≡` `×` `<` `>` `#` `♡` `▶`）。

- 社交/RSS 等使用最小化线性图标或文字标签（如 `[RSS]`）。
