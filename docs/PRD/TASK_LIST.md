## 一、说明

### 1.1 角色缩写

| 缩写 | 角色 | 并行启动条件 |
|------|------|------------|
| **ARC** | 架构师（Architect） | PRD 确认后即启动 |
| **DES** | 设计师（Designer） | PRD 确认后即启动 |
| **OPS** | 运维（DevOps） | PRD 确认后即启动（提前并行） |
| **DEV** | 开发（Developer） | 须等架构师方案 + 设计师设计稿完成 |
| **TST** | 测试（Tester） | 须等设计师视觉走查通过 |

### 1.2 并行启动规则

- 架构师、设计师、运维三者在 PRD 确认后**同时并行启动**
- 开发须等架构师技术方案与设计师设计稿**均完成**后方可开始
- 测试须等设计师视觉走查**通过**后方可开始

### 1.3 任务状态说明

- **待启动**：尚未开始
- **进行中**：正在执行
- **已完成**：已完成并交付
- **阻塞**：等待依赖或遇到问题

## 二、阶段一：架构师任务（ARC）

> 启动条件：PRD 确认后立即启动
> 交付目录：`/workspace/docs/architecture/`、`/workspace/docs/api/`

| 任务编号 | 任务名称 | 任务描述 | 交付物 | 优先级 | 依赖 |
|---------|---------|---------|--------|--------|------|
| ARC-01 | 技术栈选型 | 根据个人博客需求，选择成熟稳定的前端、后端、数据库、部署工具技术栈，输出选型说明 | 技术方案文档（TDD） | 高 | PRD |
| ARC-02 | 系统架构设计 | 设计系统分层结构、模块划分、前后端分离方案 | 技术方案文档（TDD） | 高 | ARC-01 |
| ARC-03 | 数据库设计 | 设计用户表、文章表等表结构、字段、关系、索引 | 数据库设计文档 | 高 | ARC-01 |
| ARC-04 | API 接口设计 | 设计登录、文章增删改查、后台管理等接口规范与数据格式 | API 接口文档 | 高 | ARC-02 |
| ARC-05 | 安全方案设计 | 设计认证机制（如 JWT/Session）、权限控制、密码加密方案 | 安全方案（含于 TDD） | 高 | ARC-01 |
| ARC-06 | 部署架构设计 | 设计服务器配置方案、域名规划、SSL 方案，与运维协同 | 部署架构文档 | 中 | ARC-01 |
| ARC-07 | 升级处理（如触发） | 当开发与测试闭环 3 轮未通过时，介入评估并调整技术方案，同步通知设计师 | 方案调整记录 | - | 触发时 |

**架构师交付节点：** ARC-01 至 ARC-06 完成后，将技术方案、数据库设计、API 文档交付给开发，作为开发启动前提。

## 三、阶段一：设计师任务（DES）

> 启动条件：PRD 确认后立即启动
> 交付目录：`/workspace/docs/design/`

| 任务编号 | 任务名称 | 任务描述 | 交付物 | 优先级 | 依赖 |

## 七、任务总览与依赖关系

### 7.1 任务统计

| 角色 | 任务数 | 启动时机 |
|------|--------|---------|
| 架构师（ARC） | 7 项（含 1 项升级） | PRD 确认后立即 |
| 设计师（DES） | 7 项（含 1 项变更） | PRD 确认后立即 |
| 运维（OPS） | 9 项 | PRD 确认后立即（提前并行） |
| 开发（DEV） | 12 项 | 架构方案 + 设计稿完成后 |
| 测试（TST） | 9 项（含 1 项升级） | 设计师走查通过后 |

### 7.2 关键依赖链

```
PRD 确认
  ├─ ARC-01~06 ──┐
  ├─ DES-01~05 ──┼─→ DEV-01~10 ──→ DEV-11 ──→ DES-06(走查) ──→ TST-01~08 ──→ 经理
  └─ OPS-01~05 ──┘                                                          │
                                                                            │
                              DEV 交付 ──→ OPS-06~07 ──→ TST-09(线上回归) ──→ 经理 ──→ 甲方验收
```

### 7.3 关键交接点

| 交接点 | 交接内容 | 交接方 → 接收方 |
|--------|---------|----------------|
| 方案交付 | 技术方案 + DB 设计 + API 文档 | 架构师 → 开发 |
| 设计交付 | 设计规范 + 设计稿 | 设计师 → 开发 |
| 开发完成 | 可运行源代码 | 开发 → 设计师（走查） |
| 走查通过 | 走查报告 + 代码 | 设计师 → 测试 |
| 测试完成 | 测试报告 | 测试 → 经理 |
| 部署完成 | 线上地址 | 运维 → 测试（线上回归） |
| 线上回归通过 | 线上测试报告 | 测试 → 经理 |
| 全部完成 | 最终交付汇报 | 经理 → 甲方 |
